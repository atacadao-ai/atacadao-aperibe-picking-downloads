# Picking Atacadão Aperibé

Distribuição dos APKs assinados do aplicativo interno de separação, rotas e expedição.

Baixe a atualização em Releases e instale por cima da versão anterior. O acesso aos pedidos exige conta aprovada da equipe; instalar o APK não libera acesso.

Este repositório contém os arquivos de distribuição. O desenvolvimento é mantido em repositório privado.
